QMK 磁轴键盘改键说明

本文档介绍如何通过 Remap Keys 工具对 QMK 磁轴键盘进行按键与编码器配置。目前本键盘支持按键组合、媒体按键（音量、亮度）、系统按键（休眠、睡眠）、RGB光效。
注意事项：
本键盘为磁轴键盘，允许插拔更换磁轴，请注意插拔时不要损坏亚克力面板！

步骤一：打开改键网页

在浏览器中访问以下地址：
https://remap-keys.app/configure

步骤二：连接 QMK 键盘

使用 USB 数据线将 QMK 键盘连接到电脑，确认浏览器已识别设备。

步骤三：导入 JSON 配置

点击 Import JSON 按钮，准备加载键盘配置文件。

步骤四：下载并导入配置文件

下载并导入以下配置文件：
qmkCompatibleKeyboard.json

步骤五：按键与编码器说明

  • 最上方三个按钮对应 编码器
  • 下方三个按钮对应 三个实体按键
  • 长按编码器可切换 Layer
  • 支持 RGB 灯效控制（关闭 / 自由 RGB）

步骤六：烧录配置

配置完成后，点击左上角 Flash 按钮进行烧录。

注意事项：
烧录过程中请勿断开键盘连接。完成后键盘将自动重启并应用新配置。
